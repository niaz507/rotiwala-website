# Roti Wala Snack House & Café — website

Static redesign of [rotiwala.ca](https://rotiwala.ca). Plain HTML/CSS/JS, no build step.

- `index.html` — single-page site (menu is generated from the restaurant's posted menu)
- `assets/css/styles.css`, `assets/js/main.js`
- Food photos and logo are Roti Wala's own assets from rotiwala.ca.
